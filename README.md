# SoundProof Dumps -- [Get SoundProof!](https://github.com/NuclearBlox/SoundProof-extension)
Since SoundProof is crowdsourced, it's only fair for everyone to have access to our data.
Please use this over the API.


The dumps contain artists.json and recent_changes.json. 
`artists.json` is the full dataset; `recent_changes.json` contains every new addition since the last update

If you have any questions, requests, or concerns, open an issue!

```
  {
    "id": "dragonite-lofi",
    "name": "Dragonite LOFI",
    "verified": true,
    "votes": -50,
    "human_votes": 100,
    "ai_votes": 50,
    "created_at": "2026-04-11T08:59:25.76519+00:00",
    "platform": "music"
  },

  The ID is the artist name without spaces or uppercase letters
  Name: self-explanatory 
  verified is only true when manually set
  votes are `AI votes - human votes`.
  ai_votes: self-explanatory 
  created at: self-explanatory 
  platform:  This is in case we expand into other platforms (like art), but is currently meaningless
```
